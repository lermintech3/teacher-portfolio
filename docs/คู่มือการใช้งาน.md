# คู่มือการใช้งาน แฟ้มสะสมผลงานครู

## 1. เว็บมี 2 หน้า

| หน้า | ลิงก์ | ใครใช้ |
| --- | --- | --- |
| หน้าสาธารณะ | `https://teacher-portfolio-cth.pages.dev/` | ทุกคน รวมถึง ผอ. และกรรมการประเมิน เห็นเฉพาะรายการที่ตั้งเป็น "สาธารณะ" |
| หน้าครู | `https://teacher-portfolio-cth.pages.dev/admin/` | ครูคนเดียว ต้องใส่รหัสผ่าน เห็นและแก้ไขได้ทุกอย่าง |

หน้าสาธารณะไม่มีปุ่มหรือลิงก์ไปหน้าครู ให้บันทึกลิงก์ `/admin/` ไว้ในเบราว์เซอร์ของตัวเอง

## 2. เข้าใช้ครั้งแรก

1. เปิด `/admin/` แล้วใส่รหัสผ่านที่ตั้งไว้ใน Cloudflare (ตัวแปร `ADMIN_PASSWORD`)
2. ระบบถามวิธีเริ่มต้น
   - **เริ่มจากว่าง**: พาไปหน้าโปรไฟล์ให้กรอกข้อมูลจริงทันที
   - **เริ่มด้วยข้อมูลตัวอย่าง**: ได้ข้อมูลตัวอย่างครบทุกเมนูไว้ลองใช้ รายการตัวอย่างขึ้นต้นด้วย "(ตัวอย่าง)" ลบหรือแก้ทีหลังได้
3. ระบบจำการเข้าสู่ระบบไว้ 30 วันในเครื่องนั้น ถ้าใช้คอมส่วนกลางให้กด **ออกจากระบบ** ทุกครั้ง

ถ้าเปลี่ยนรหัสผ่านใน Cloudflare ทุกเครื่องจะต้องเข้าสู่ระบบใหม่ ถ้าใส่รหัสผิด 5 ครั้ง ระบบล็อก 15 นาที

## 3. การใช้งานประจำวัน

- **เพิ่มข้อมูล**: กดปุ่ม `+ เพิ่ม...` สีเข้มที่หัวหน้า กรอกฟอร์มแล้วกด บันทึก
- **แก้ไข / ลบ**: ทุกรายการมีปุ่ม `แก้ไข` และ `ลบ` (ลบแล้วกู้คืนไม่ได้ ยกเว้นจากไฟล์สำรอง)
- **สาธารณะ / ส่วนตัว**: แตะป้ายสีในรายการเพื่อสลับ รายการใหม่เป็นส่วนตัวเสมอ ต้องเลือกเองถ้าจะเผยแพร่
- **เมนูที่เป็นส่วนตัวเสมอ** (เปลี่ยนเป็นสาธารณะไม่ได้): งานที่ต้องทำ กำหนดส่ง นักเรียน เช็กชื่อ คะแนน ดูแลช่วยเหลือ หนังสือราชการ บันทึกการประชุม การลา ประวัติ สอนแทน

| อยากทำ | ไปที่เมนู |
| --- | --- |
| ดูคาบสอนวันนี้ งานค้าง วันกำหนดส่ง | แดชบอร์ด |
| ใส่ชื่อ ตำแหน่ง รูป ปรัชญาการสอน | โปรไฟล์ |
| ใส่คาบสอน ภาคเรียน เวลาคาบ | ตารางสอน |
| เพิ่มนักเรียน เช็กชื่อ | รายชื่อและเช็กชื่อ (แตะช่องเพื่อเปลี่ยน มา → สาย → ลา → ขาด บันทึกเอง) |
| กรอกคะแนน ตัดเกรด | การวัดผล (ปพ.5) ปุ่ม "ตั้งค่าวิชา" เปลี่ยนสัดส่วนคะแนนได้ |
| เก็บหลักฐาน PA | คลังหลักฐาน (ใส่รหัสตัวชี้วัด เช่น 1.3, 1.6) แล้วดูภาพรวมที่เมนู PA |
| ทำ SAR | SAR ประเมินตนเอง (ดึงข้อมูลอัตโนมัติ กด "พิมพ์ / บันทึกเป็น PDF") |
| ใส่ไฟล์ SAR/PA ให้คนอื่นดาวน์โหลด | การเผยแพร่ → เพิ่มรายงาน SAR / PA (ใส่ลิงก์ PDF จาก Google Drive) |

รูปและไฟล์ตอนนี้ใส่เป็นลิงก์ (เช่น ลิงก์ Google Drive ที่ตั้งเป็น "ทุกคนที่มีลิงก์ดูได้") ระยะ 3 จะมีปุ่มอัปโหลดโดยตรง

## 4. ปรับแต่งเว็บเอง (เมนู ตั้งค่าเว็บ)

| ปรับอะไรได้ | วิธี |
| --- | --- |
| ชื่อเว็บ | กด "แก้ไข" ที่หัวข้อชื่อเว็บ |
| ชื่อเมนู สีเมนู ซ่อน/แสดงเมนู | กด "ปรับ" ที่เมนูนั้น ใช้ได้ทั้งหน้าสาธารณะและหน้าครู เมนูที่ซ่อนข้อมูลยังอยู่ครบ |
| ตัวเลือกในฟอร์ม เช่น ประเภทงาน ระดับรางวัล | กด "แก้ไข" ที่ช่องนั้น พิมพ์บรรทัดละตัวเลือก |
| ตัวชี้วัด PA ให้ตรงแบบฟอร์มโรงเรียน | กด "แก้ไข" ที่หัวข้อตัวชี้วัด PA บรรทัด `# ...` คือชื่อด้าน บรรทัด `รหัส \| ชื่อ` คือตัวชี้วัด |
| กลับไปค่าตั้งต้น | กด "คืนค่าตั้งต้นทั้งหมด" (ข้อมูลอื่นไม่หาย) |

หน้าแดชบอร์ด หน้าแรกสาธารณะ และหน้าตั้งค่าเว็บ ซ่อนไม่ได้ เพื่อไม่ให้เข้าหน้าตั้งค่าไม่ได้

## 5. สำรองข้อมูล (แนะนำเดือนละครั้ง)

เมนู **สำรองข้อมูล**
- **ดาวน์โหลดไฟล์สำรอง**: ได้ไฟล์ `.json` เก็บไว้ใน Google Drive ส่วนตัว ไฟล์นี้มีข้อมูลนักเรียน อย่าแชร์
- **กู้คืน**: เลือกไฟล์สำรองแล้วกด กู้คืนข้อมูล (ข้อมูลปัจจุบันจะถูกแทนที่ทั้งหมด)

## 6. ข้อมูลเก็บที่ไหน

- ข้อมูลทั้งหมดอยู่ในฐานข้อมูล Cloudflare D1 ชื่อ `teacher-db` (ฟรี 5 GB)
- รหัสผ่านอยู่ใน Cloudflare เป็น Secret ไม่มีใน GitHub
- โค้ดอยู่ใน GitHub ทุกครั้งที่โค้ดเปลี่ยน Cloudflare จะ deploy ใหม่เอง ข้อมูลไม่หาย

## 7. แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
| --- | --- |
| "ยังไม่ได้ผูกฐานข้อมูล D1" | Cloudflare → โปรเจกต์ → Settings → Bindings → เพิ่ม D1 ชื่อตัวแปร `DB` แล้ว deploy ใหม่ |
| "ยังไม่ได้ตั้งรหัสผ่าน ADMIN_PASSWORD" | Settings → Variables and Secrets → เพิ่ม Secret ชื่อ `ADMIN_PASSWORD` แล้ว deploy ใหม่ |
| หน้าสาธารณะยังเป็นข้อมูลตัวอย่าง | เข้าหน้าครูแล้วกรอกโปรไฟล์ หน้าสาธารณะจะใช้ข้อมูลจริงทันทีที่มีโปรไฟล์ |
| ลืมรหัสผ่าน | ตั้งรหัสใหม่ใน Cloudflare แล้ว deploy ใหม่ (Deployments → Retry deployment) |
