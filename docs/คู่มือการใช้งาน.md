# คู่มือการใช้งาน แฟ้มสะสมผลงานครู

## 1. หน้าต่างๆ ของเว็บ

เว็บนี้มีแฟ้มผลงาน 2 คน ข้อมูลและรหัสผ่านแยกกันทั้งหมด

| หน้า | ลิงก์ | ใครใช้ |
| --- | --- | --- |
| หน้าแรก | `https://teacher-portfolio-cth.pages.dev/` | ทุกคน เห็นโปรไฟล์ 2 คน กดเลือกเพื่อเข้าแฟ้มผลงาน |
| แฟ้มผลงานครูเฉลิมพล | `/chalermphon/` | ทุกคน เห็นเฉพาะรายการที่ตั้งเป็น "สาธารณะ" |
| แฟ้มผลงานครูวราภรณ์ | `/waraporn/` | ทุกคน เห็นเฉพาะรายการที่ตั้งเป็น "สาธารณะ" |
| หน้าครู | `/admin/` | ใช้ลิงก์เดียวกันทั้งสองคน รหัสผ่านของใคร ระบบเปิดข้อมูลของคนนั้น |

ส่งลิงก์ให้ ผอ. ได้ 2 แบบ: ส่งหน้าแรก (เห็นทั้งสองคน) หรือส่งลิงก์แฟ้มของตัวเองโดยตรง

มีปุ่ม "สำหรับครู: เข้าสู่ระบบ" ที่ด้านล่างหน้าแรก และ "เข้าสู่ระบบครู" ที่ด้านล่างเมนูของแฟ้มผลงาน (คนอื่นกดได้แต่เข้าไม่ได้ถ้าไม่มีรหัส)

### รหัสผ่านของแต่ละคน (ตั้งใน Cloudflare → Settings → Variables and Secrets แบบ Secret)

| คน | ชื่อตัวแปร |
| --- | --- |
| เฉลิมพล | `ADMIN_PASSWORD` (ตัวเดิม) หรือ `PASSWORD_CHALERMPHON` |
| วราภรณ์ | `PASSWORD_WARAPORN` |

รหัสของสองคนต้องไม่ซ้ำกัน ตั้งหรือเปลี่ยนรหัสใน Cloudflare แล้วต้อง deploy ใหม่ 1 ครั้ง

### เปลี่ยนรหัสผ่านเอง (ไม่ต้องเข้า Cloudflare)

หน้าครู → **ตั้งค่าเว็บ → เปลี่ยนรหัสผ่าน** ใส่รหัสปัจจุบัน และรหัสใหม่ 2 ครั้ง (อย่างน้อย 8 ตัวอักษร)
- เครื่องที่กำลังใช้อยู่ไม่ต้องเข้าใหม่ เครื่องอื่นที่เคยเข้าสู่ระบบไว้จะต้องเข้าใหม่ด้วยรหัสใหม่
- รหัสที่ตั้งเองเก็บแบบเข้ารหัสทางเดียว (PBKDF2) ในฐานข้อมูล ไม่มีใครอ่านรหัสจริงได้ รวมถึงผู้ดูแล
- **ลืมรหัส:** ตั้งค่าใหม่ใน Cloudflare (ตัวแปรตามตารางด้านบน) แล้ว deploy ใหม่ รหัสที่เคยตั้งเองจะถูกยกเลิก กลับไปใช้รหัสใน Cloudflare

## 2. เข้าใช้ครั้งแรก

1. เปิด `/admin/` แล้วใส่รหัสผ่านของตัวเอง
2. ระบบถามวิธีเริ่มต้น
   - **เริ่มจากว่าง**: พาไปหน้าโปรไฟล์ให้กรอกข้อมูลจริงทันที
   - **เริ่มด้วยข้อมูลตัวอย่าง**: ได้ข้อมูลตัวอย่างครบทุกเมนูไว้ลองใช้ รายการตัวอย่างขึ้นต้นด้วย "(ตัวอย่าง)" ลบหรือแก้ทีหลังได้
3. ระบบจำการเข้าสู่ระบบไว้ 30 วันในเครื่องนั้น ถ้าใช้คอมส่วนกลางให้กด **ออกจากระบบ** ทุกครั้ง

ถ้าเปลี่ยนรหัสผ่านใน Cloudflare ทุกเครื่องจะต้องเข้าสู่ระบบใหม่ ถ้าใส่รหัสผิด 5 ครั้ง ระบบล็อก 15 นาที

## 3. การใช้งานประจำวัน

- **เพิ่มข้อมูล**: กดปุ่ม `+ เพิ่ม...` สีเข้มที่หัวหน้า กรอกฟอร์มแล้วกด บันทึก
- **แก้ไข / ลบ**: ทุกรายการมีปุ่ม `แก้ไข` และ `ลบ` (ลบแล้วกู้คืนไม่ได้ ยกเว้นจากไฟล์สำรอง)
- **สาธารณะ / ส่วนตัว**: แตะป้ายสีในรายการเพื่อสลับ รายการใหม่เป็นส่วนตัวเสมอ ต้องเลือกเองถ้าจะเผยแพร่
- **เมนูที่เป็นส่วนตัวเสมอ** (เปลี่ยนเป็นสาธารณะไม่ได้): งานที่ต้องทำ กำหนดส่ง นักเรียน เช็กชื่อ คะแนน ดูแลช่วยเหลือ หนังสือราชการ บันทึกการประชุม การลา ประวัติ สอนแทน

| อยากทำ | ไปที่เมนู |
| --- | --- |
| ดูคาบสอนวันนี้ งานค้าง วันกำหนดส่ง | แดชบอร์ด |
| ใส่ชื่อ ตำแหน่ง รูป ปรัชญาการสอน | โปรไฟล์ |
| ใส่คาบสอน ภาคเรียน เวลาคาบ | ตารางสอน |
| เพิ่มนักเรียน เช็กชื่อ | รายชื่อและเช็กชื่อ (แตะช่องเพื่อเปลี่ยน มา → สาย → ลา → ขาด บันทึกเอง) |
| กรอกคะแนน ตัดเกรด | การวัดผล (ปพ.5) ปุ่ม "ตั้งค่าวิชา" เปลี่ยนสัดส่วนคะแนนได้ |
| เก็บหลักฐาน PA | คลังหลักฐาน (ใส่รหัสตัวชี้วัด เช่น 1.3, 1.6) แล้วดูภาพรวมที่เมนู PA |
| ทำ SAR | SAR ประเมินตนเอง: ดูตัวอย่างเป็นหน้า A4 ตามแบบฟอร์มโรงเรียน (ตอนที่ 1–3) เลือกปีการศึกษาด้านบน แตะช่องในตารางเพื่อติ๊ก ✓ ปุ่มแก้ไขข้างหัวข้อ (สีเขียว = ดึงจากเมนูอื่นอัตโนมัติ) แล้วกด "พิมพ์ / บันทึกเป็น PDF" |
| ใส่ไฟล์ SAR/PA ให้คนอื่นดาวน์โหลด | การเผยแพร่ → เพิ่มรายงาน SAR / PA (ใส่ลิงก์ PDF จาก Google Drive) |

## 5. แนบไฟล์และรูป (Google Drive)

ช่องไฟล์ในฟอร์มแนบได้ 3 แบบ: **ลากไฟล์มาวาง**, กด **เลือกไฟล์** (บนมือถือเลือกจากคลังรูปหรือถ่ายรูปได้) หรือ **วางลิงก์** (Google Drive, YouTube, เว็บอื่น)

- ไฟล์ไม่เกิน 20 MB รูปถูกย่อเหลือด้านยาว 1280 px ให้อัตโนมัติ
- เก็บใน Google Drive ของคุณครูตามโครงสร้างนี้

```
โฟลเดอร์หลัก/
  เฉลิมพล จันทร์แดง/
    รูปโปรไฟล์/  เกียรติบัตรและรางวัล/  การอบรมและพัฒนาตนเอง/  แผนการสอนและสื่อ/
    บันทึกหลังสอน/  การนิเทศ/  ผลงาน วิจัย นวัตกรรม/  รายงาน SAR และ PA/  หลักฐาน PA/
    โครงการ/  กิจกรรมพัฒนาผู้เรียน/  งานที่รับผิดชอบ/  หนังสือราชการ/  บันทึกการประชุม/
    ดูแลช่วยเหลือนักเรียน/  การลา/  อื่นๆ/
  วราภรณ์ สุขหยอม/
    (เหมือนกัน)
```

- โฟลเดอร์สร้างเองตอนอัปโหลดไฟล์แรกของหมวดนั้น
- ไฟล์ในหมวด หนังสือราชการ, บันทึกการประชุม, ดูแลช่วยเหลือนักเรียน, การลา **ไม่แชร์** (เปิดได้เฉพาะเจ้าของบัญชี Google)
- หมวดอื่นตั้งเป็น "ทุกคนที่มีลิงก์ดูได้" เพื่อให้รูปแสดงในหน้าสาธารณะได้ (แต่ต้องตั้งรายการเป็นสาธารณะในเว็บด้วย คนอื่นจึงจะเห็น)
- เมนู **ไฟล์ใน Google Drive** ดูไฟล์ทั้งหมดของตัวเอง อัปโหลดหลายไฟล์พร้อมกัน คัดลอกลิงก์ หรือย้ายไปถังขยะ (กู้คืนได้ใน Drive 30 วัน)

### ติดตั้งการเชื่อม Google Drive (ทำครั้งเดียว ใช้ร่วมกันทั้งสองคน)

1. **ตั้งโฟลเดอร์หลักเป็น "จำกัด" (Restricted)** ไม่ต้องแชร์ให้ใคร
2. เปิด [script.google.com](https://script.google.com) ด้วยบัญชีที่เป็นเจ้าของโฟลเดอร์ → **New project**
3. คัดลอกโค้ดทั้งหมดจากไฟล์ `google-apps-script/Code.gs` ใน GitHub ไปวางแทนโค้ดเดิม → กดบันทึก (ไอคอนแผ่นดิสก์)
4. ⚙️ **Project Settings** → เลื่อนลงไปที่ **Script Properties** → **Add script property**
   - Property: `SECRET`  Value: รหัสลับยาวๆ ที่คิดเอง (อย่างน้อย 20 ตัว ห้ามใช้ซ้ำกับรหัสผ่านเว็บ)
5. **Deploy → New deployment** → กดรูปเฟือง เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy → **Authorize access** → เลือกบัญชี → ถ้าขึ้น "Google hasn't verified this app" กด Advanced → Go to (ชื่อโปรเจกต์) → Allow
   - คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
6. Cloudflare → โปรเจกต์ → Settings → Variables and Secrets
   - `DRIVE_SCRIPT_URL` (Text) = Web app URL
   - `DRIVE_SECRET` (Secret) = รหัสลับเดียวกับข้อ 4
7. Deployments → **Retry deployment**
8. เข้าหน้าครู → เมนู **ไฟล์ใน Google Drive** ถ้าขึ้นปุ่ม "เปิดโฟลเดอร์ของฉันใน Google Drive" แปลว่าเชื่อมสำเร็จ

ถ้าแก้โค้ด Apps Script ทีหลัง ต้อง Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version → Deploy (URL เดิมใช้ต่อได้)

## 5.2 จัดหน้าแรกเอง (ลากวาง)

| ทำอะไร | วิธี |

| ซ่อน / แสดง | กดปุ่ม "แสดงอยู่ / ซ่อนอยู่" บล็อกที่ซ่อนจะจางลง |

บล็อกที่มี: แบนเนอร์และโปรไฟล์, ปรัชญาการสอน, ตัวเลขผลงาน, สไลด์โชว์, ผลงานและเกียรติบัตรเด่น, อัลบั้มล่าสุด, Facebook ล่าสุด (โหลดเมื่อเลื่อนถึง), ความเคลื่อนไหวล่าสุด, ความพึงพอใจ (คะแนนเฉลี่ย + QR ไม่แสดงความคิดเห็น), วิดีโอแนะนำ, เหรียญความสำเร็จ, ประวัติการศึกษาและการติดต่อ
บล็อกที่ยังไม่มีข้อมูลสาธารณะจะไม่แสดงให้คนอื่นเห็น

## 5.3 AI ผู้ช่วย (อ่านเกียรติบัตรแล้วกรอกฟอร์มให้)

ครูแต่ละคนใส่ API key ของตัวเองได้ เลือกค่ายได้ 3 ค่าย: Claude (Anthropic), ChatGPT (OpenAI), Gemini (Google) ค่าใช้จ่ายคิดกับบัญชีของครูคนนั้นโดยตรง

**เจ้าของเว็บทำครั้งเดียว:** Cloudflare → โปรเจกต์ → Settings → Variables and Secrets → Add → ชนิด Secret ชื่อ `AI_SECRET` ค่าเป็นข้อความสุ่มยาวอย่างน้อย 16 ตัว (หน้าตั้งค่าในเว็บสุ่มให้ดูได้) → Save → Deployments → Retry deployment
- `AI_SECRET` ใช้เข้ารหัส API key ของครูทุกคนก่อนเก็บลงฐานข้อมูล ถ้าเปลี่ยนภายหลัง ครูทุกคนต้องใส่ API key ใหม่

**ครูแต่ละคน:**
1. ขอ API key จากค่ายที่ต้องการ (ลิงก์อยู่ในหน้า ตั้งค่าเว็บ → AI ผู้ช่วย)
2. ตั้งค่าเว็บ → แท็บ AI ผู้ช่วย → ตั้งค่า → เลือกค่าย วางคีย์ → บันทึก → กด "ทดสอบ"
3. เมนูเกียรติบัตรและรางวัล หรืออบรม / PLC → เพิ่มรายการ → ปุ่ม **✨ อ่านด้วย AI** → เลือกรูปหรือ PDF
4. AI กรอกช่องให้ (แถบม่วง = AI กรอก, แถบเหลือง = AI ไม่แน่ใจ ให้ตรวจ) แล้วกดบันทึกเอง ระบบไม่บันทึกให้อัตโนมัติ

ใช้ AI ได้ที่:
| เมนู | วิธีใช้ |
|---|---|
| ตารางสอน | ปุ่ม **✨ นำเข้าจากรูป** → เลือกรูป/PDF ตารางสอน → ติ๊กเลือกคาบ → เลือก "ล้างตารางเดิม" หรือ "เพิ่มลงตารางเดิม" |
| คำสั่ง | ปุ่ม **✨ อ่านคำสั่งด้วย AI** → AI กรอกเลขที่ วันที่ เรื่อง และแยกงานที่มีชื่อครู → ตรวจแล้วบันทึก **ไม่เก็บไฟล์คำสั่ง** |
| เกียรติบัตร, อบรม, โครงการ, นิเทศ, หนังสือราชการ, ประชุม, กิจกรรม, ผลงาน, การลา, งานที่รับผิดชอบ | เพิ่มรายการ → **✨ อ่านด้วย AI** |
| หลักฐาน | พิมพ์ชื่อหลักฐาน → **✨ แนะนำหมวดจากชื่อ** AI เลือกตัวชี้วัด PA หัวข้อ SAR และเมนูที่มาให้ |

ความปลอดภัย: คีย์เก็บที่เซิร์ฟเวอร์แบบเข้ารหัส หน้าเว็บเห็นแค่ตัวย่อ เรียก AI ได้เฉพาะตอนล็อกอินหน้าครู ตั้งเพดานจำนวนครั้งต่อเดือนได้ ไฟล์ที่ให้ AI อ่านจะถูกส่งไปยังค่ายที่เลือก

## 5.4 ติดตั้งเป็นแอปบนมือถือ

หน้าครูติดตั้งเป็นแอปได้ จะมีไอคอน "แฟ้มครู" บนหน้าจอ เปิดแบบเต็มจอเหมือนแอปทั่วไป
- **Android / Chrome / Edge:** เมนูด้านข้าง → ปุ่ม **ติดตั้งแอปลงมือถือ** → ติดตั้ง
- **iPhone / iPad (Safari):** แตะปุ่มติดตั้ง จะมีวิธีบอก: ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม → เพิ่ม (ครั้งแรกที่เปิดจากไอคอนต้องใส่รหัสผ่านอีกครั้ง)
- **เปิดลิงก์จาก LINE:** ติดตั้งไม่ได้ ต้องกด "เปิดในเบราว์เซอร์" ก่อน
- กดค้างที่ไอคอน (Android) จะมีทางลัดไป ตารางสอน เกียรติบัตร บันทึกหลังสอน และ SAR
- แอปอัปเดตเองทุกครั้งที่เปิดตอนมีเน็ต ไม่ต้องติดตั้งใหม่

## 5.5 เมนูคำสั่ง

เก็บคำสั่งแต่งตั้งที่ได้รับ (เลขที่ ลงวันที่ เรื่อง ผู้ออกคำสั่ง ปีการศึกษา) และงานที่ต้องทำในแต่ละคำสั่ง **ไม่เก็บไฟล์คำสั่ง**
- เพิ่มด้วย AI: ✨ อ่านคำสั่งด้วย AI → เลือกรูป/PDF → ตรวจข้อมูล ติ๊กเลือกงาน → บันทึก ไฟล์ถูกส่งให้ AI อ่านแล้วทิ้ง
- เพิ่มเอง: + เพิ่มคำสั่ง แล้วกด "+ เพิ่มงานในคำสั่งนี้"
- แตะป้ายสถานะของงานเพื่อเปลี่ยน: ยังไม่ทำ → กำลังทำ → เสร็จ งานเวรและครูที่ปรึกษาเป็น "ทั้งปี" ไม่มีสถานะ
- ข้อมูลคำสั่งไปอยู่ใน SAR ให้เอง:
  - 1.2.4 งานพิเศษ: ชื่องานพร้อม (คำสั่งที่ …)
  - 1.2.5 คำสั่งแต่งตั้งที่ได้รับ: ตาราง เลขที่ ลงวันที่ เรื่อง และหน้าที่ของครูในแต่ละคำสั่ง (ไม่แสดงในฉบับเผยแพร่)
  - 3.2 หน้าที่อื่นที่ได้รับมอบหมาย: งานในคำสั่งขึ้นก่อน พร้อม "ตามคำสั่งที่ …" งานที่ตั้งสถานะเสร็จจะมีเหตุผลตั้งต้นให้
- งานเดิมที่เขียนเลขที่คำสั่งไว้ กด "จัดกลุ่มเข้าเมนูคำสั่ง" ครั้งเดียว ระบบสร้างคำสั่งตามเลขที่และผูกงานให้
- คำสั่งเป็นข้อมูลส่วนตัวเสมอ ไม่ขึ้นหน้าสาธารณะ

## 5.6 ตารางสอนหลายภาคเรียน

- หน้าตารางสอนมีแถบเลือกภาคเรียน เช่น ภาคเรียน 2/2569 · ปัจจุบัน / ภาคเรียน 1/2569 แต่ละภาคเรียนมีตารางและเวลาคาบของตัวเอง
- **+ ภาคเรียนใหม่**: เลือกภาคเรียน แล้วคัดลอกตารางจากภาคเรียนที่กำลังดู หรือเริ่มจากตารางว่าง (ใช้เวลาคาบเดิม) หรือกด ✨ นำเข้าจากรูป
- **ภาคเรียนปัจจุบัน** ใช้แสดงในหน้าแรกและหน้าสาธารณะ ระบบเปลี่ยนให้เองเมื่อถึงภาคเรียนใหม่ตามวันที่ (ภาคเรียนที่ 1 = 16 พ.ค.–31 ต.ค., ภาคเรียนที่ 2 = 1 พ.ย.–15 พ.ค.) และภาคเรียนนั้นมีตารางแล้ว
- ตั้งเองได้ด้วยปุ่ม "ตั้งเป็นภาคเรียนปัจจุบัน" ระบบจะไม่สลับกลับจนกว่าจะขึ้นภาคเรียนถัดไป ปิดการเปลี่ยนอัตโนมัติได้ที่ "ภาคเรียนและเวลาคาบ"
- SAR ข้อ 1.2.1 ดึงตารางทั้งภาคเรียนที่ 1 และ 2 ของปีการศึกษานั้นเอง

## 5.7 ชุดสีและไอคอนเมนู

- ทุกเมนูมีไอคอนแบบเส้น สีตามสีประจำเมนู (ทั้งหน้าครูและหน้าสาธารณะ)
- ตั้งค่าเว็บ → ทั่วไป → **ชุดสี**: ม่วงสดใส (แบบเดิม) หรือ พาสเทล ใช้กับทั้งหน้าครูและหน้าสาธารณะ เปลี่ยนแล้วบันทึกทันที
- สีเมนูที่ตั้งเองในแท็บ "เมนู" จะคงไว้ ไม่เปลี่ยนตามชุดสี
- รูปเล่ม SAR ยังเป็นขาวดำเทาเหมือนเดิม ไม่เปลี่ยนตามชุดสี

## 6. สำรองข้อมูล (แนะนำเดือนละครั้ง)

เมนู **สำรองข้อมูล**
- **ดาวน์โหลดไฟล์สำรอง**: ได้ไฟล์ `.json` เก็บไว้ใน Google Drive ส่วนตัว ไฟล์นี้มีข้อมูลนักเรียน อย่าแชร์
- **กู้คืน**: เลือกไฟล์สำรองแล้วกด กู้คืนข้อมูล (ข้อมูลปัจจุบันจะถูกแทนที่ทั้งหมด)

## 7. ข้อมูลเก็บที่ไหน

- ข้อมูลทั้งหมดอยู่ในฐานข้อมูล Cloudflare D1 ชื่อ `teacher-db` (ฟรี 5 GB) ทุกแถวมีช่อง `site` บอกว่าเป็นของใคร ระบบแก้ได้เฉพาะข้อมูลของคนที่ล็อกอิน
- รหัสผ่านอยู่ใน Cloudflare เป็น Secret ไม่มีใน GitHub
- ไฟล์และรูปอยู่ใน Google Drive ของเจ้าของโฟลเดอร์ (ฐานข้อมูลเก็บแค่ลิงก์)
- โค้ดอยู่ใน GitHub ทุกครั้งที่โค้ดเปลี่ยน Cloudflare จะ deploy ใหม่เอง ข้อมูลไม่หาย
